# Battery SOH & SOC Prediction Using Deep Learning

A research-oriented battery analytics project that predicts:
- State of Health (SOH)
- State of Charge (SOC)

Models included in the research code:
- Multi-Head Attention LSTM (MHA-LSTM)
- GCN-LSTM
- Attention-LSTM
- Temporal Convolution Network (TCN)

Dataset:
NASA Battery Dataset (B0005, B0007, B0018)

## Installation

pip install -r requirements.txt

## Run

python src/train.py
